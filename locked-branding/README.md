# locked-branding

Brand-lock files (icons, favicons, OG images) that must **never** be packed into
any distribution zip (`dist/`, `playgama/`, `cert/` all assert this).

Drop the approved Cut the Fuse icon set here as `icon-192-LOCKED.png`,
`icon-512-LOCKED.png`, `favicon-LOCKED.ico`, `og-LOCKED.png`, etc. Bundle
scripts ship only runtime assets (`index.html`, `src/`, `assets/`).
