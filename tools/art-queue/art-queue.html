Cut the Fuse art queue

One PNG per row. Copy the subject or the full prompt → paste into Gemini → cut out / remove background in Canva → save to assets/<file>. Dropping a PNG into assets/ auto-upgrades the game (LevelManager.resolveAssets). File names come straight from src/data/skins.js — the skin registry — so they always match what the game loads. The 6 starter files are already done; anything missing just falls back to the starter art. Works from the dev server or opened directly (file://). If you add a new character to src/data/skins.js, regenerate this list with npm run art:queue:gen.
